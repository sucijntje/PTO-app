PTO + SCHOOLROOSTER 1E — GECOMBINEERDE PWA

Dit vervangt de huidige PTO-PWA.

Als je dezelfde bestaande GitHub repository 'PTO-app' wilt blijven gebruiken:
1. Open de repository.
2. Verwijder/vervang de oude bestanden in de root.
3. Upload ALLE bestanden uit deze ZIP:
   - index.html
   - rooster.html
   - manifest.webmanifest
   - service-worker.js
   - icon-180.png
   - icon-192.png
   - icon-512.png
4. Commit de wijzigingen.

Je GitHub Pages-adres blijft hetzelfde.

Na de update op de iPhone:
- Open de app.
- Als de oude versie nog zichtbaar is, sluit de app helemaal af en open opnieuw.
- Als nodig: verwijder de app van het beginscherm en voeg hem opnieuw toe via Safari.

Bovenaan staan nu twee hoofdtabbladen:
PTO | Schoolrooster

Deze versie gebruikt GEEN kleurcodes per vak in het schoolrooster.
